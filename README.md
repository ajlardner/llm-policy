# llm-policy
My thoughts and rules for agentic coding and LLM usage

## General LLM Usage
Large amounts of code for various projects may be generated by LLMs. My development process is focused on always fully understanding the content of the code in all of my projects, and sometimes generating varying amounts of the overall project's code with an LLM is an effective method of increasing efficiency, learning more, and writing more effective code. However, all code committed to released or in-use versions of my projects will be fully reviewed and understood by a human before reaching that point. A zero-trust-in-the-LLM model seems to be the most effective choice at the moment.

## Accountability
The human author is responsible for all code in generated by the LLM. "The agent wrote it" is never a reason that something went wrong. If you let the agent write it, you wrote it.
