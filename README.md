# llm-policy
My thoughts and rules for agentic coding and LLM usage

**ALL PROJECTS CONTAINING ANY AMOUNT OF LLM-GENERATED CODE ARE INDICATED AS SUCH WITH A DISCLAIMER AND A LINK TO THIS REPO IN THE README**

## General Thoughts
I have not found LLMs to be particularly intelligent. In my experience they are not capable of consistently writing complex code, let alone complex programs. Letting an LLM or a group of LLMs write and/or maintain a complex program is not something I personally see going well. In my workflow and experience, LLMs are good for answering questions or certain coding tasks, as long as they have the right harness and tooling around them, good prompts, and tight constraints. These systems are still evolving and I don't see them as useful in the way that some industries are touting them quite yet, and I'm not sure LLM technology in it's current form can do that at all. I am very willing to be proven wrong on that.

Simply, you cannot trust a non-deterministic system. Those who claim to be on the quest for AGI want you to believe it is close enough to, and even one step away from, being intelligent enough that it doesn't need to be deterministic to be trusted with work that is currently trusted to humans. I have a hard time believing that.

If you are willing to specify absolutely everything an agent needs to do at every step, and review *everything* they do *at every single step*, you can get some good results. I have found that a lot of the time, doing this takes as much time / effort as doing it myself, without the valuable processes of trial and error that are essential to the way I learn.

It's also possible, if you're willing to pay through the nose for tokens on the latest SotA frontier models, to get an LLM to write fairly coherent code in a fairly context complex. However, I can't afford to and don't want to pay for that, and at the end of the day, its still non deterministic (and annoying) and I don't trust it.

LLMs and AI chatbots are also just very annoying to me. I am deeply annoyed by the way they write, both prose and code. It's like if you combined the worst opinions and typing patterns of every reddit user distilled through the most annoying posts they've ever written and then asked it to be your personal assistant. Even if it's getting things done, I am very very rarely better off for having interacted with LLM-generated content and I wish it worked very differently.

At least for the time being, I am ok with using LLMs to answer questions that I would be answering by looking through search engine results otherwise, in which case I am careful to review the sources it provides and do not trust the knowledge of the model, essentially making it a slightly more efficient search engine. I also think it can be productive to use an LLM to generate small amounts of boilerplate code or structured data that I'd likely be copying from StackOverflow or documentation anyways. For example, Pi Coding Agent did a decent enough job writing a [theme for itself](https://github.com/ajlardner/pi-coding-agent-config/blob/main/agent/themes/more-contrast.json), which is literally just JSON, with some fairly simple constraints and the context provided by the Pi documentation.

I'm also careful about sandboxing for any kind of agentic process. Any kind of agent can never be trusted with the ability to perform permanently destructive actions. For that reason, the first question I ask when using or designing any kind of technology that interacts with an LLM is "how can I make this thing completely harmless." My Pi Coding Agent configuration and extension code, for example, has more LLM generated code than other things I do. Pi is allowed to edit those files, and I may use it's code with extensive human review. Someone else has done a ton of work to allow Pi to understand how to extend itself, and it seems to be okay at that, so I am more willing to allow it to generate code in that context - as long as the code it generates can still respect my desire for the LLM to be completely harmless. 


## Rules
- If I could ever think "oh shit" after doing something, that is not something the LLM is allowed to do
- Any repository or project containing LLM generated code will be clearly indicated as such in the readme
- Any files containing any amount of code generated by an LLM will be explicitly marked with a comment with the following content:
```bash
# THIS FILE WAS GENERATED AND / OR EDITED BY AN LLM
# all code in this file was reviewed and understood by a human before use or public release
# the human owner of this software or data assumes all responsibility for the output of an LLM or agent harness they prompted
# harness - harness_name (e.g. Pi Coding Agent) 
# model - developer_name/model_name (e.g. anthropic/claude opus 4.5)
# see https://github.com/ajlardner/llm-policy/
```
